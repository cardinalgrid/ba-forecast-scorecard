# Contributing

Issues, pull requests and replications are welcome.

- Use public data only. Do not submit proprietary, employer or customer data, even as samples.
- Every analysis must be reproducible: include the notebook or script and pin the data snapshot or the download step.
- Report results with their limitations. A method that underperforms a baseline is still a result.
- Keep numbers sourced: any figure in a README or note links to its public source.
- Corrections are welcome. Open an issue with the reproduction; corrections are logged in the changelog of the archived record.

By contributing you agree that code is released under Apache-2.0 and text/figures under CC BY 4.0.
