# Contributing

Issues, pull requests and replications are welcome.

- Only public data is used in this project.
- Analyses should be reproducible: include the script or notebook and the data download step.
- Figures quoted in documentation should link to their public source.
- To report an error, open an issue with the steps to reproduce it.

By contributing you agree that code is released under Apache-2.0 and text/figures under CC BY 4.0.
